# 📘 Guía Rápida de Usuario - Voltia Solutions

> Una guía simple y visual para empezar a usar el sistema rápidamente

---

## 🚀 Inicio Rápido

### 1️⃣ Acceder al Sistema

1. Abre tu navegador y ve a la URL del CRM
2. Introduce tu **usuario** y **contraseña**
3. Haz clic en **"Iniciar Sesión"**

💡 **Primera vez**: Si olvidaste tu contraseña, contacta al administrador.

---

## 👥 Gestión de Clientes

### ➕ Crear un Nuevo Cliente

```
Menú → Clientes → Botón "Nuevo Cliente"
```

**Datos mínimos necesarios:**
- ✅ Tipo: Particular o Pyme
- ✅ Nombre completo
- ✅ DNI/CIF
- ✅ Teléfono
- ✅ Email
- ✅ IBAN

**Documentos a adjuntar:**
- 📄 DNI (anverso y reverso) si es Particular
- 📄 DNI + CIF + Escrituras si es Pyme

**Guardar** → Listo ✅

### 🔍 Buscar un Cliente

Usa los **filtros** en la parte superior:
- Por nombre
- Por teléfono
- Por email
- Por DNI

Los resultados se actualizan mientras escribes.

### ✏️ Editar un Cliente

1. Busca el cliente
2. Clic en el icono **✏️ Editar**
3. Modifica lo necesario
4. **Guardar**

---

## 📋 Gestión de Contratos

### ⚡ Contrato de Energía

#### Crear Nuevo Contrato

**Opción A - Desde Clientes:**
```
Editar Cliente → Botón "Crear Contrato Energía"
```

**Opción B - Desde Contratos:**
```
Menú → Contratos Energía → "Nuevo Contrato" → Seleccionar Cliente
```

**Datos obligatorios:**
- ✅ Tipo de operación (Cambio comercializadora, Alta nueva...)
- ✅ Comercializadora
- ✅ Tarifa
- ✅ Dirección de suministro completa

**Datos importantes opcionales:**
- 🔌 CUPS Luz / Gas
- 📊 Potencia contratada (kW)
- 📈 Consumo anual (kWh)

**Documentos:**
- 📄 PDF del contrato firmado
- 📄 Facturas (opcional)

#### Cambiar Estado de Contrato

1. **Editar** el contrato
2. Cambiar el **Estado**:
   - 📝 En tramitación
   - ⏳ Pendiente
   - ✅ **Activo** ← registra fecha de activación
   - ❌ Cancelado
   - 🚫 Rechazado
3. **Guardar**

> 💡 Al poner "Activo", el sistema te pedirá la **fecha de activación**

---

### 📱 Contrato de Telefonía

```
Menú → Contratos Telefonía → "Nuevo Contrato"
```

**Datos obligatorios:**
- ✅ Operadora (Movistar, Vodafone, Orange...)
- ✅ Tipo de tarifa (Convergente, Solo móvil, Solo fibra...)
- ✅ Tarifa principal
- ✅ Dirección de instalación

**Líneas telefónicas:**
- 📞 Línea principal (fijo o móvil)
- 📱 Hasta 5 líneas adicionales
- Para móviles: tipo (Contrato/Prepago) y código ICC

**Instalación:**
- 📅 Fecha de instalación
- ⏰ Horario preferido

---

### 🔔 Contrato de Alarmas

```
Menú → Contratos Alarmas → "Nuevo Contrato"
```

**Datos obligatorios:**
- ✅ Empresa de alarma
- ✅ Tipo de inmueble (Hogar/Negocio)
- ✅ Subtipo (Piso, Chalet, Local, Oficina...)
- ✅ Kit de alarma
- ✅ Campaña aplicable
- ✅ Dirección de instalación

**Si tiene contrato anterior:**
- ☑️ Marca "Tiene contrato anterior"
- Indica compañía, número de contrato y fecha de permanencia

## 📊 Funciones Útiles

### 🔎 Filtrar Contratos

Cada tipo de contrato tiene **filtros avanzados**:
- Por cliente (nombre, teléfono, email)
- Por comercializadora/operadora
- Por estado
- Por CUPS (energía) o línea (telefonía)

### 📥 Exportar a Excel

**Desde listado de contratos:**
1. Aplica los filtros que necesites
2. Clic en **"Exportar a Excel"**
3. Elige formato:
   - **Completo**: Todos los datos
   - **Reducido**: Solo campos principales

### 📝 Agregar Observaciones

En cualquier contrato:
1. Ve a la sección **"Observaciones"**
2. Escribe tu nota
3. Clic en **"Agregar"**

✅ Se guarda con fecha, hora y tu usuario  
❌ Solo puedes eliminar tus propias observaciones

### 📄 Adjuntar Documentos

**En contratos:**
1. Ve a **"Documentación"**
2. Clic en **"Seleccionar archivos"**
3. Elige el archivo (PDF, JPG, PNG, DOC, DOCX)
4. Se sube automáticamente

**Descargar documentos:**
- Clic en el botón **⬇️ Descargar** junto al archivo

## 🔧 Configuración de Usuario

### Cambiar Contraseña

```
Menú de usuario (esquina superior derecha) → "Cambiar Contraseña"
```

1. Introduce tu **contraseña actual**
2. Introduce la **nueva contraseña** (mínimo 6 caracteres)
3. **Confirma** la nueva contraseña
4. Clic en **"Cambiar Contraseña"**

> ⚠️ Tras cambiar la contraseña, se cerrará tu sesión automáticamente

### Cerrar Sesión

```
Menú de usuario → "Cerrar Sesión"
```

## 💡 Consejos Rápidos

### ✨ Mejores Prácticas

1. **📝 Documenta todo**: Usa las observaciones para registrar llamadas, incidencias o cambios
2. **📎 Adjunta archivos**: Mantén toda la documentación en el sistema
3. **✅ Valida antes de guardar**: Los campos con * son obligatorios
4. **🔍 Usa filtros**: Encuentra información rápidamente
5. **💾 Exporta periódicamente**: Haz backup de tus datos
6. **🔐 Protege tu contraseña**: Cámbiala regularmente

### 🚫 Errores Comunes

❌ **"Campo obligatorio"** → Completa todos los campos con *  
❌ **"IBAN inválido"** → Verifica el formato del IBAN  
❌ **"No se puede activar"** → Introduce la fecha de activación  
❌ **"Archivo muy grande"** → Reduce el tamaño del PDF (máx 5MB)

## 🎯 Tareas Más Comunes

### Dar de alta un cliente nuevo con contrato de energía
```
1. Clientes → Nuevo Cliente
2. Rellenar datos + adjuntar DNI
3. Guardar
4. Clic en "Crear Contrato Energía"
5. Rellenar datos del contrato
6. Adjuntar contrato firmado
7. Guardar
```

### Activar un contrato pendiente
```
1. Buscar el contrato
2. Editar
3. Cambiar Estado a "Activo"
4. Introducir fecha de activación
5. Agregar observación (opcional)
6. Guardar
```

### Consultar activaciones del mes
```
1. Log de Activaciones
2. Filtrar por fecha: Desde 01/MM/AAAA Hasta 31/MM/AAAA
3. Exportar a Excel (opcional)
```
